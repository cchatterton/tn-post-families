# Changelog

All notable changes to TN Post Families are recorded here.

## 1.1.0 - 2026-11-05

- On a Page whose slug matches a registered post type, list that type's top-level items and nested children in menu order.
- Keep the existing family links and omit items the current user cannot edit.

## 1.0.1 - 2026-10-25

- Show children and siblings by WordPress menu order, using title to break ties.

## 1.0.0 - 2026-10-25

- Released WordPost Family's parent, child and sibling editor navigation as TN Post Families.
- Improved link permissions, native editor URLs, empty state, accessibility and scoped styling.
- Added Techn Update Controller integration and GitHub release packaging.
